1. 전달받은 diff가 있으면 그것만 봅니다. 없으면 git diff HEAD(커밋 전) 또는 git diff main...HEAD(PR 브랜치)로 이번 변경만 읽습니다.
2. 반복문 안의 DOM 조회·innerHTML 갱신, 같은 값의 중복 계산, 불필요하거나 반복되는 네트워크 요청, 커지기만 하는 데이터 파일, 레이아웃을 흔드는 CSS, 해제되지 않는 이벤트 리스너를 확인합니다.
